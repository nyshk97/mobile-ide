# プロジェクト一覧（#5）

## 概要・やりたいこと

PolePole の `projects.json` をそのまま使い、iPhone のホームにプロジェクト一覧を出す。タップでそのプロジェクトの tmux セッションに入る。管理を二重化しない（README「PolePole でピン留めしているプロジェクト一覧をそのまま使う」）。

- ピン留め（PolePole のピン順）と、その他（最近開いた順）の 2 セクション
- `tmux list-sessions` と突き合わせ、生きているセッションがある行にマーク
- `HomeView` の `mobile-ide` ハードコードを消し、`TerminalTarget` は一覧の行から作る

GitHub Issue: nyshk97/mobile-ide#5

## 前提・わかっていること

### 決定事項（/dig-lite）

- **tmux セッション名は path のディレクトリ名から作る**（`/Users/d0ne1s/video-player` → `video-player`）。`[A-Za-z0-9_-]` 以外は `-` に置き換える。一覧内で重複したら親ディレクトリ名を `-` で後ろに付けて区別する。今の `mobile-ide` セッションはそのまま引き継がれる
- **一覧はピン留め + その他の 2 セクション**。ピン留めは配列順（= PolePole のピン順）、その他は `lastOpenedAt` 降順
- **生きているセッションのマーク**: `session_name` が一致する行に印。`session_attached >= 1` なら「接続中」の別表示
- **取得は 1 往復の exec**（PATH 前置き）。表示のたびに接続して閉じる。更新は表示時と pull-to-refresh
- **色は `colorKey` をアイコンの色に**。PolePole の 10 色の RGB を写す
- 失敗時は一覧の場所にエラーと再試行

### 調査で確定した事実

- `projects.json` は `~/Library/Application Support/polepole/projects.json`。`{ schemaVersion: 1, projects: [{ id, path, displayName, isPinned, lastOpenedAt(ISO8601), colorKey?, paneLayout? }] }`。今 27 件、ピン 7 件。PolePole のサイドバーは `restored.filter { $0.isPinned }`（配列順）+ 一時プロジェクト（`lastOpenedAt` 降順）
- `colorKey`: red / orange / yellow / green / mint / teal / blue / indigo / purple / pink。RGB は `~/ide/Sources/polepole/ProjectColor.swift`（例: mint = 0.36, 0.82, 0.71）
- tmux 3.7 は `.` / `:` を含むセッション名を作れるが `-t` で指定できない（ターゲット構文の区切り）。実測して session_id 指定で掃除した
- tmux サーバーが無いとき `list-sessions` は exit 1（`no server running`）。`|| true` で吸収し、空として扱う
- exec チャネルは `.zshrc` を読まない。`PATH=/opt/homebrew/bin:$PATH` を前置きする（`cat` は不要だが `tmux` に必要）
- 1 往復のコマンド案:
  ```sh
  PATH=/opt/homebrew/bin:$PATH; cat "$HOME/Library/Application Support/polepole/projects.json"; printf '\n---SESSIONS---\n'; tmux list-sessions -F '#{session_name}\t#{session_attached}\t#{session_activity}' 2>/dev/null || true
  ```
- #4 の成果: `SSHConnection.connect(settings:identity:knownHosts:)` が接続の唯一の入口。`ConnectionSettings.isConfigured`。`LaunchOptions` で自走用の環境変数

### 設計

```
Core/Projects/Project.swift             projects.json の Decodable（Project / ProjectsFile）と ProjectColor（colorKey → Color）
Core/Projects/TmuxSessionName.swift     path → セッション名（サニタイズ + 重複回避）
Core/Projects/ProjectListLoader.swift   SSHConnection で接続 → 1 往復 exec → JSON と tmux 一覧を parse → [ProjectRow]（pinned / others に分けて返す）
Core/Projects/ProjectListModel.swift    @Observable。state: loading / loaded(pinned, others, fetchedAt) / failed(String)。refresh()
Features/Home/HomeView.swift            List: ピン留め / その他。行: 色付きアイコン、displayName、path 末尾、セッション状態のバッジ。pull-to-refresh。タップ → TerminalScreen(target)
Features/Home/ProjectRowView.swift      行の見た目
Features/Terminal/TerminalTarget.swift  `init(project:)`（sessionName は TmuxSessionName、workingDirectory は path）
```

- `ProjectRow`: `project`, `sessionName`, `sessionState: .none / .alive / .attached`
- `TmuxSessionName.make(for projects:) -> [Project.ID: String]`。基本は `URL(fileURLWithPath:).lastPathComponent` をサニタイズ。同名が複数あれば `<basename>-<parent>` にする
- 自走用: 起動時に一覧を読み終えたら `PROJECTS loaded pinned=<n> others=<n> alive=<names>` を stdout に出す。失敗は `PROJECTS failed <reason>`。`MOBILE_IDE_OPEN_PROJECT=<sessionName>` で一覧から該当行を自動で開く（`MOBILE_IDE_TERMINAL_AUTORUN` の置き換え。`TERMINAL_AUTORUN` は互換のため `mobile-ide` を開くことにする）。`scripts/console-run.py` の MARKERS に `PROJECTS ` を追加

### 方針変更
