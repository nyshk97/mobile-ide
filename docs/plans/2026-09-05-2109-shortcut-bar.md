# ショートカットバー（#13）

## 概要・やりたいこと

端末の下に常駐するキーボードバー（#6）を「Claude Code / Codex を使う」動線に合わせて整理する。汎用の端末キー（esc / ctrl / ⇧tab / `~ / - |`）を落とし、代わりに Claude / Codex の起動、git の pull / push、Claude Code のスラッシュコマンドをワンタップで流せるようにする。

- Claude のマーク → `claude --dangerously-skip-permissions` を実行
- Codex のマーク → `codex -a never -s danger-full-access` を実行
- git のマーク → メニュー: `gpull` / `gpush`
- スラッシュのマーク → メニュー: `/` `/dig` `/dig-lite` `/plot` `/polish-plan` `/polish-plan-codex` `/act` `/polish-impl` `/polish-impl-codex` `/retro` `/resume`
- キー: tab / ^C / ← ↓ ↑ → / ⏎
- キーボード切替（右端固定）は残す

GitHub Issue: nyshk97/mobile-ide#13

## 前提・わかっていること

### 決定事項（モック → 案 A）

モック `shortcut-bar-mock.html`（scratchpad）で 3 案（A: 1 段 + ポップアップ / B: 2 段 / C: 1 段 + インライン入れ替え）を比べ、**A** を採用。

- **1 段のまま**。並びは `[Claude] [Codex] [git] [/] | tab ^C | ← ↓ ↑ → ⏎ | ⌨`。今と同じ高さで端末が狭くならない。iPhone 幅では ⏎ が横スクロール先に落ちるのは許容（折りたたみ内側では 1 行に収まる）
- **git とスラッシュは SwiftUI の `Menu`**（ネイティブのコンテキストメニュー風ポップアップ。画面下端のボタンからは上に開く）。モックの 2 列表示は `Menu` では作れないので 1 列。並びは issue の順
- **Claude / Codex / gpull / gpush は Enter まで送る**（文字列 + `\r`）。押した瞬間に実行される
- **スラッシュコマンドは文字列だけ流し、Enter は送らない**。`/dig 〜` のように引数を続けられる。`/` 単独は Claude Code の補完リストを出す用途。**`/` 以外は末尾に空白を付ける**（`/dig` で止めると補完リストが `/dig` と `/dig-lite` を候補に出したまま Enter を待つ状態になる。空白で補完を閉じておけば、続けて Enter を押せば `/dig` が走り、引数を打ってもよい）
- **落とすもの**: esc / ctrl（ワンショット）/ ⇧tab / `~ / - |`。Claude Code の中断は esc なので迷ったが、issue の一覧を正として外す。復活させたくなったら `TerminalKey` にケースは残っているので並びに足すだけ
- issue の `/polish-impl` が 2 回書かれているのは `/polish-impl-codex` の誤記と解釈（`/polish-plan` / `/polish-plan-codex` と対になる）
- `gpull` / `gpush` は `.zshrc` の alias（`git pull origin <現在のブランチ>` / `git push origin <現在のブランチ>`）。アプリは alias 名をそのまま流す（ホスト側の alias に依存。無ければ `command not found` が見えるだけ）

### 調査で確定した事実

- 現行 `KeyboardBar.Action` は `.key(TerminalKey)` / `.toggleControl` / `.toggleKeyboard`。`TerminalScreen.perform` が `surface.send(bytes:)` に流す。Ctrl ワンショットの配線（`isControlArmed` / `surface.controlPending` / `onControlReset`）は ctrl ボタンを落とすと**全部 dead code になる**ので、`TerminalSurface` protocol の `controlPending` / `onControlReset` と `SwiftTermSurface` の実装（`controlModifier` の reset 通知の購読）ごと消す
- `TerminalKey` は esc 等のケースを持ち、バイト列のテスト（`TerminalKeyTests`）がある。enum はそのまま残し、バーが出すキーだけ絞る（テストも残す）
- `send(text:)` は SwiftTerm の `send(txt:)` → `onInput` → `PTYSession.send`。コマンドの流し込みはこの経路（画像添付の `@path ` の流し込みと同じ）。`\r` を末尾に付ければ Enter になる（`TerminalKey.enter` は `0x0d`）
- 自走検証は `MOBILE_IDE_PRESS_KEYS`（DEBUG）で `KeyboardBar.Action(name:)` を順に呼ぶ。名前空間を広げる: `claude` / `codex` / `gpull` / `gpush` / `/dig` 等（`/` で始まる名前はスラッシュコマンドの挿入）
- Air には `codex`（`/opt/homebrew/bin/codex`）が入っている
- アイコン: Claude / Codex / git の商標ロゴは SF Symbols に無い。`Path` / `Rectangle` で描く小さな SwiftUI ビューを 1 ファイルにまとめる（Clawd 風のピクセル絵・六角形の結び目・git のブランチ図）。スラッシュは `Text("/")`

### 設計

```
Features/Terminal/KeyboardBar.swift     Action: .key(TerminalKey) / .shortcut(Shortcut) / .toggleKeyboard（.toggleControl を削除）

Features/Terminal/ShortcutIcons.swift   ClaudeMark / CodexMark / GitMark（SwiftUI で描く）
Features/Terminal/TerminalScreen.swift  perform: .shortcut → surface.send(text:)。isControlArmed / onControlReset の配線を削除
Core/Terminal/TerminalSurface.swift     controlPending / onControlReset を削除

```

目印行: 既存の `KEYS pressed <name>` に `.shortcut` も乗せる（`KEYS pressed claude` / `KEYS pressed /dig`）。
