# GitHub から mini に clone して開く

## 概要・やりたいこと
MacBook Air で新規作成したプロジェクトが Mac mini に無く、外出先の iPhone から触れないことがある。新規プロジェクトは作成時に GitHub へ push 済み（運用で担保済み）なので、iPhone から mini に clone できれば足りる。

1. **「GitHub から追加」画面**: mini で GitHub のリポジトリ一覧を取り、mini に無いものに印を付けて並べる。タップで mini に clone して、そのまま tmux の端末を開く。clone 済みの行はタップでそのまま開く
2. **ホームの「その他」に PolePole 未登録の git リポジトリも出す**: clone しただけのプロジェクトは mini の PolePole の `projects.json` に載っていないので、このままだと次回から一覧に出ない。`projects.json` には書き込まず（PolePole の持ち物で、起動中の PolePole に上書きされうる。README の「管理を二重化しない」）、読むときに `~/` を走査して補う

## 前提・わかっていること
- **対象リポジトリ**: 個人（nyshk97）+ org `d0ne1s-mikkame` だけ。org はコードの定数で固定（仕事の org `lincwell` / `web-billing` / `general-ccdn` は出さない）。アーカイブ済みは除外し、`pushedAt` 降順。Air で見える個人 repo は 106 件なので `--limit` は余裕を持って取る
- **clone 先は `~/<repo名>` 固定**。`~/dm/` 配下に置きたいものは後で Mac で mv する（一覧の走査は 2 段なので mv 後も出る）。既に同名のパスがあれば clone せずエラー表示
- **clone 済みの判定は `origin` の URL**（ディレクトリ名でなく）。`git@github.com:o/r.git` / `https://github.com/o/r(.git)` を `o/r`（小文字）に正規化して突き合わせる
- **未登録 repo の走査範囲**: `~/*/.git` と `~/*/*/.git` の 2 段。`~/Library` と `~/.*` は除外。zsh の exec ではマッチしないグロブがエラーになるので `find "$HOME" -maxdepth 3 ... -prune -o -name .git -print` で取る（`-mindepth` を付けると深さ 1 の `~/Library` に prune が効かず中まで潜る。`~/Dropbox` の symlink は find が辿らない）
- **mini の gh は SSH の exec から認証できない**（2026-09-27 に実測: `gh auth status` が `The token in default is invalid`）。token がログインキーチェーンにあり、sshd 経由では開いていないため（tmux 内の claude と同じ問題）。mini 固有ではなく macOS の gh の既定（`gh auth login` はキーチェーンに保存）で、Air も `ssh localhost` 経由だと同じく失敗する。SSH から gh を叩かれるのは mini だけなので、Air はキーチェーンのままでよい。→ 事前準備で mini の gh を `--insecure-storage`（`~/.config/gh/hosts.yml` に平文で保存。hosts.yml は Dropbox 外のローカルファイル）で入れ直す
- **clone は `gh repo clone` でなく `git clone git@github.com:<o>/<r>.git`**: gh の `git_protocol` は https で、https の認証は gh の credential helper 経由になる。GitHub への SSH 鍵認証は mini の exec から通ることを実測済み（`ssh -T git@github.com` → `Hi nyshk97!`）。`~/.ssh` と `known_hosts` は Dropbox で共有
- 一覧の取得は `ProjectListLoader.command` の exec 1 往復。ここに走査の出力を `---REPOS---` 区切りで足す（往復を増やさない）。exec は `.zshrc` を読まないので PATH は前置き済み（git は `/usr/bin/git`、gh は `/opt/homebrew/bin/gh`）
- `Project` には memberwise init が既にある。未登録 repo はそれで合成する（`id` = path、`displayName` = ディレクトリ名、`isPinned` = false、`lastOpenedAt` = `.git/index` の mtime、`colorKey` = nil → 既存の自動色）
- 「その他」の並びは、PolePole の `lastOpenedAt` と未登録 repo の `.git/index` mtime を混ぜて降順
- **tmux のセッション名は全パスの集合で決まる**（`TmuxSessionName.names(forPaths:)` は同名があると親ディレクトリ名を付ける）。未登録 repo も含めた全パスで計算しないと、ホームと「GitHub から追加」で同じディレクトリに別のセッション名が付く。clone 直後に開くときも、既存の全パス + 新パスで計算する
