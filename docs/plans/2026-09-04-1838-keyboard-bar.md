# キーボードバーと日本語入力（#6）

## 概要・やりたいこと

Claude Code / Codex を iPhone で実用的に操作できるキー入力を整える。SwiftTerm 標準のアクセサリ（esc / ctrl / tab / 矢印）を外し、端末の下に常駐する自前のキーボードバーを置く。「動く」ではなく「使える」を判定する段階なので、最終判断は実機。

- Esc / Ctrl（ワンショット）/ Tab / Shift+Tab / ← ↓ ↑ → / Enter
- 記号 `/` `-` `|` `~`、Ctrl+C 専用キー、キーボードの表示・非表示
- 日本語入力は確定後にだけ送られることを確認する（SwiftTerm の既存動作）
- ソフトウェアキーボード表示時のリサイズは #3 で確認済み

GitHub Issue: nyshk97/mobile-ide#6

## 前提・わかっていること

### 決定事項（/dig-lite）

- **バーは端末の下に常駐**。キーボードの有無に関係なく見える。キーボードの表示・非表示はバーのボタン（`becomeFirstResponder` / `resignFirstResponder`）。SwiftTerm 標準のアクセサリは `inputAccessoryView = nil` で外す
- **キー**: Esc / Ctrl / Tab / Shift+Tab / ← ↓ ↑ → / Enter / `/` `-` `|` `~` / Ctrl+C / キーボード切替。今の iPhone では横スクロール、折りたたみの内側画面（7.8 インチ、4:3）では 1 行に収まる想定
- **Ctrl はワンショット**。SwiftTerm の `TerminalView.controlModifier = true` を立てるだけで、次に打った 1 文字に Ctrl が乗って自動で false に戻る。バー側は選択状態の見た目だけ持ち、SwiftTerm が false に戻したときの通知（`.terminalViewControlModifierReset`）で見た目も戻す
- **矢印はアプリケーションカーソルモードで切り替える**（`ESC [ A` ↔ `ESC O A`）。`getTerminal().applicationCursor` を見る。長押しでリピート（0.5 秒後から 0.1 秒間隔）
- **日本語入力は新たに実装しない**。SwiftTerm は `setMarkedText`（未確定）をホストに送らず `unmarkText`（確定）で `insertText` する。実機の確認項目にする
- バーは SwiftUI で端末画面の一部として書く。送信は `TerminalSurface` に足したメソッド越しに行い、SwiftTerm 依存を `SwiftTermSurface` に閉じる

### 調査で確定した事実（SwiftTerm 1.20.0）

- public: `send(_ bytes: [UInt8])`、`send(txt: String)`、`controlModifier`、`metaModifier`、`inputAccessoryView`（set 可）、`getTerminal()`。internal: `sendKeyUp` 等、`insertTextFromAccessory`
- `insertText` は `terminalAccessory?.controlModifier || controlModifier` を見て Ctrl を適用し、両方 false に戻す。false に戻るとき `Notification.Name.terminalViewControlModifierReset` を post
- `Terminal.applicationCursor` の可視性は未確認（`getTerminal()` は public なので、public でなければ `EscapeSequences` 相当を自前で持ち、モードは DECCKM の追跡が要る。plan 実装時に最初に確認する）
- 既定のアクセサリは `setupAccessoryView()` で生成され `inputAccessoryView` に入る。後から nil を代入すれば消える
- 折りたたみ iPhone は手元に無い。レイアウトは横幅で自然に 1 行 / スクロールになる作りにしておく

### 設計

```
Core/Terminal/TerminalSurface.swift     追加: send(bytes:) / send(text:) / var controlPending / var usesApplicationCursorKeys / showKeyboard() / hideKeyboard() / onControlReset
Core/Terminal/SwiftTermSurface.swift    上記の SwiftTerm 実装。inputAccessoryView = nil。controlModifier の reset 通知を購読
Core/Terminal/TerminalKey.swift         enum TerminalKey（esc, tab, shiftTab, enter, ctrlC, up, down, left, right, slash, dash, pipe, tilde）と bytes(applicationCursor:) / label / systemImage
Features/Terminal/KeyboardBar.swift     SwiftUI。横スクロールの HStack。Ctrl と キーボード切替はトグル表示。矢印は長押しリピート
Features/Terminal/TerminalScreen.swift  VStack { TerminalSurfaceView; KeyboardBar }。キーボードの表示状態は UIResponder.keyboardWillShow/Hide で追跡
```

- 自走用（DEBUG）: `MOBILE_IDE_PRESS_KEYS=esc,tab,shiftTab,up,enter,ctrlC` のように書くと、接続後 `MOBILE_IDE_TERMINAL_TYPE` の送信の 1 秒後に、バーのボタンと同じハンドラを順に 0.3 秒間隔で呼ぶ。stdout に `KEYS pressed <name>` を出す
